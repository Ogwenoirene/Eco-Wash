# EcoWash

EcoWash is a website for an eco-friendly laundry pickup and delivery service. Customers can see clear prices, learn how the service works, and book a laundry pickup online.

## Features

- **Home page** with a hero section (text on the left, image on the right), a transparent price list in KES, and a three-step "How It Works" guide
- **Booking page** where customers choose a service, pick home pickup or self drop-off, set a date and time window, add eco care preferences, and leave gate or stain notes
- **Responsive layout** that works on phones, tablets, and desktops
- **Combined footer** with the business address, phone link, social icons, and copyright

## Pages

| File | Purpose |
| --- | --- |
| `index.html` | Home page: hero, price list, how it works, footer |
| `book.html` | Pickup booking form |
| `orders.html` | Orders page (linked in the navigation) |
| `account.html` | Login page (linked in the navigation) |

## Built With

- HTML5
- [Tailwind CSS v4](https://tailwindcss.com/) via the browser CDN build
- [Font Awesome](https://fontawesome.com/) for the social icons

No build step or installation is needed.

## Getting Started

1. Download or clone the project.
3. Open `index.html` in your browser.

An internet connection is required.


## Customizing

- **Colors:** the site uses Tailwind's green palette (green-50, green-600, green-800). Change those class names to restyle it.
- **Prices:** edit the table in index.html and the service options in book.html.
- **Contact details:** the address and phone number in the footer of each page.
- **Social links:** the footer icons are  available
